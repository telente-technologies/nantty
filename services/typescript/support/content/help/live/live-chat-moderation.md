Live chat moves fast. These tools help hosts keep it friendly, and explain to viewers why a comment might not go through.

## Who this is for

Hosts and the moderators they choose. Viewers can read the "If something goes wrong" section below.

## Room settings (host)

- **Comments on or off**: turn chat off completely for the live.
- **Slow mode**: make each viewer wait between comments, up to 5 minutes.
- **Blocked words**: add up to 100 words or phrases (2 to 30 characters each). Comments containing them aren't posted.

Settings apply to that live and change instantly for everyone watching.

## Moderators

The host can make trusted viewers moderators for a live, and remove them at any time. The host and moderators can:

- delete comments
- mute a viewer, so they can watch but not comment
- remove a viewer from the live, so they can't rejoin it

Moderators can't mute or remove the host or other moderators.

## Pinned comment

The host can pin one comment to the top of chat, for example rules or a link to a product, and unpin it later.

## Good to know

- Comments can be up to 300 characters.
- Muting or removing someone only applies to that live. To stop someone everywhere, [block them](/help/profiles-and-privacy/blocking-people).
- For serious harm, report the person or the live. See [Live safety](/help/live/live-safety).
- Our automatic safety checks run on every live, whatever your chat settings.

## If something goes wrong

These are the messages viewers see:

- **"The host turned comments off for this live."** Chat is closed for now.
- **"Slow mode is on. Wait a moment before commenting again."** Wait, then send again.
- **"That comment contains words that are not allowed in this live."** Rephrase your comment.
- **"You are muted in this live."** A host or moderator muted you. You can still watch.
- **"You were removed from this live."** You can't rejoin this live.
- **"Only the host or a moderator can do that."** You tried a moderation action without permission.
- **"The host and moderators can't be muted or removed by a moderator."**
