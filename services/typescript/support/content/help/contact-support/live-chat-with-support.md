You don't need a separate chat tool. Every support request is a conversation you can continue in real time.

## How it works

1. Send a request from **Settings > Support > Contact support**.
2. Open it from **My support requests**.
3. When an agent picks it up, their replies appear as they send them. You'll see **Zudomart Support is typing…** while they write.
4. Reply in the box at the bottom. Add screenshots if they help.

If you leave the screen, you'll get a notification and an email when the agent replies, so you can carry on later.

## Recording and privacy

A notice in the chat reminds you: this chat is not end-to-end encrypted. It is recorded and reviewed for quality and safety. That's different from your private chats with other people, which Zudomart can't read. See [End-to-end encryption](/help/chat/end-to-end-encryption).

## When the chat ends

When your issue is sorted, the agent marks the request **Resolved** and you can rate the help you got. If the problem comes back within 7 days, reply to reopen it. After that, start a new request.

## Good to know

- Agents work through requests by priority. Payment and safety problems come first.
- Keep one request per problem so the agent has the whole story.

## If something goes wrong

- **"This chat has ended."** Start a new request from **Contact support**.

## Stay safe

Never share passwords, card PINs or one-time codes, even with a support agent. See [What support will never ask for](/help/contact-support/what-support-never-asks).
