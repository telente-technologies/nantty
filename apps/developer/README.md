# Nantty Developer Portal

Standalone Next.js workspace for the future public API and business-integration console.

Run locally with `pnpm --filter @nantty/developer dev` (port 3700).

Current scope is an honest, responsive portal foundation only. The public business API, centralized SSO, organization/role service, credentials, webhooks, usage ledger, and billing APIs are not implemented, so this app does not create keys, make API requests, or show sample production data. Do not deploy it as an operational developer console until those backend controls and authentication are in place.
