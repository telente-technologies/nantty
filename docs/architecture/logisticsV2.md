# Logistics V2 proposal — superseded

This document path is retained only because historical changelog entries and
older links reference it. The proposal here is no longer the active plan:
Natty logistics is now scoped as V1, with optional Kwikpik provider delivery
and seller-managed delivery retained.

See the current, source-reviewed contract and implementation status in
[logisticsV1.md](logisticsV1.md). Natty's product version is independent of the
Kwikpik Partnership API version (currently documented by Kwikpik as v2).
