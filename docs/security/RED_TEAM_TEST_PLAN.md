# Nantty Adversarial Red Team Test Plan (Phase 2)

| Scenario ID | Threat Vector | Target Component | Adversarial Payload / Technique | Expected Outcome & Status |
| --- | --- | --- | --- | --- |
| `RT-01` | Gateway Path Confusion & Internal Route Smuggling | `services/typescript/gateway` | `//evil.example/api/v1/auth/login`, `//api/v1/admin/users`, `/api/v1//admin/users`, `/api/v1/%61dmin/users`, `/api/v1/auth/%2e%2e/internal/x` | Blocked with `404` before upstream dispatch (`gatewayPathConfusion.test.ts`: **PASS 7/7**; `gatewayHardening.handler.test.ts`: **PASS**) |
| `RT-02` | Anonymous Mutation & Suspended Account Bypass | `services/typescript/gateway` | Unauthenticated `POST`/`PATCH`/`DELETE` across 1,261 routes; suspended account mutating non-appeal routes | Denied `401`/`403` (`anonymousMutations.handler.test.ts`: **PASS 1,261/1,261**; `suspendedAndRoutingHardening.test.ts`: **PASS**) |
| `RT-03` | Widget Token Privilege Escalation | `services/typescript/gateway` | Presenting `widget` scope token to `/api/v1/wallets/me` or `/api/v1/orders` | Denied `401 WIDGET_TOKEN_SCOPE` (`widgetTokenScope.routes.test.ts`: **PASS**) |
| `RT-04` | BFF CSRF, Open Redirect & Clickjacking | `apps/{developer,sandbox,webapp,seller,ads,admin,studio}` | Cross-origin POSTs, `Origin` match with `Sec-Fetch-Site: cross-site`, `?next=https://evil.com`, iframe embedding of `/api/*` or `/bff/*` | Blocked `403 CSRF_REJECTED`, fallback safe relative redirect, `frame-ancestors 'none'` + `no-store` (`apps/developer` **PASS 35/35**, `apps/sandbox` **PASS 1/1**) |
| `RT-05` | Sandbox Webhook SSRF & DNS Rebinding | `services/typescript/sandbox` | Webhook URLs targeting `169.254.169.254`, `100.64.0.1`, `::1`, `::ffff:127.0.0.1`, Teredo `2001::1`, 6to4 `2002::1`, mixed public+private DNS answers | Rejected `WEBHOOK_HOST_NOT_PUBLIC` before TCP connect (`webhookSecurity.test.ts`: **PASS 14/14**) |
| `RT-06` | Paid Scheduling Entitlement Bypass | `services/typescript/social` | Expired-subscription author calls `POST /api/v1/scheduled-posts/:id/publish-now` | Rejected `403 PAID_SCHEDULING_REQUIRED` (Fix implemented; runtime test blocked on Prisma engine download from `binaries.prisma.sh`) |
| `RT-07` | Black Government Verification Separation Bypass | `services/go/modules/subscriptions` | Revoking/deleting verification before in-flight checkout payment webhook settles | Fails closed (`StatusPaused` / `StatusCanceled`), never `StatusActive` (Fix implemented + integration test added; requires `go` toolchain + Postgres) |
| `RT-08` | Apple/Google IAP Receipt Cross-Account Renewal Takeover | `services/go/modules/subscriptions` | User B submits month-2 renewal `StoreTransactionId` sharing User A's `OriginalTransactionId`, or User A rebinds to another profile | Rejected `409 STORE_RECEIPT_ALREADY_REDEEMED` / `403 ErrProfileNotEligible` (Fix implemented + integration test added; requires `go` toolchain + Postgres) |
| `RT-09` | Ad Click Open Redirect & Signed Click Forgery | `services/go/modules/ads` + `gateway` | Tampered click token or `javascript:`/`http:`/`user:pass@` redirect target | Rejected by `Signer.VerifyClick`, `IsSafeClickTarget`, and Gateway `isSafeRedirectLocation` (`adRedirect.handler.test.ts`: **PASS 4/4**) |
| `RT-10` | E2EE Ratchet, Replay & Plaintext Injection | `packages/chatCrypto` + `social` | Corrupted AEAD tags, skipped-key flood (>2000), malformed envelopes, plaintext fields on encrypted chat routes | Rejected (`ChatCryptoError` / `assertNoPlaintext`) (`@nantty/chat-crypto`: **PASS 98/98**) |
| `RT-11` | Intelligence HMAC Replay & Body Exhaustion | `services/python/intelligence` | Reused nonce, stale timestamp, oversized body (>limit), decoded vs raw path differential | Rejected `401`/`413`/`503` (Code-audited; `pytest` unavailable in sandbox) |
