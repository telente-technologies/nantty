## Cleared Non-Issues Investigated During Audit

- **`POST/DELETE /api/v1/stores/*/follow` -> `commerce`**: `catalog/src/modules/stores/routes/stores.routes.go` intentionally handles these endpoints and delegates internally to `social`.
- **`POST /api/v1/reports` dynamic routing (`social` -> `trust`)**: `upstreamDispatch.handler.ts` intentionally inspects JSON payload to route conversation/group reports to `trust` while keeping feed/post reports on `social`.
- **`apps/messenger/ios/NanttyMessenger/Info.plist`**: `NSAllowsArbitraryLoads` is `false` (only `NSAllowsLocalNetworking` is enabled).
- **`services/go/modules/auth/src/modules/developerProduction`**: `authenticateLiveCredential` verifies both `c.status = 'active'` and `a.status = 'approved'`.
- **`/api/v1/verification/*` in `routeInventory.py`**: `verificationMoneyRoutes` in `verificationMoney.routes.ts` is spread into `upstream.routes.ts:35` and correctly routes Black & verification billing endpoints to `money`.
