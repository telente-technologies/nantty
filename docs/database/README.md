## 3. Per-module map (Go, ent + golang-migrate format generated by Atlas)

Every Go module with a database uses the same layout. `<m>` = `services/go/modules/<module>`.

| Artifact | Path pattern |
| --- | --- |
| ent schema (source of truth for tables) | `<m>/src/databases/schema/*.schema.go` (+ `timeOrderedIdentifier.mixin.go`: UUIDv7 `id`, immutable `created_at`) |
| ent codegen entry | `<m>/src/databases/generate.go` (`go generate`; features `sql/lock, sql/versioned-migration, sql/execquery, sql/upsert, sql/schemaconfig`) |
| Generated client | `<m>/src/generated/ent/` (never edit; `migrate/schema.go` = expected tables) |
| Migration generator | `<m>/cmd/generateMigration/main.go` (`go run ./cmd/generateMigration <name>`; `-rehash` after hand-written files; uses `ATLAS_DEV_DATABASE_URL`, default `atlas_dev` on :15432) |
| Migrations | `<m>/src/migrations/<ts>_<name>.{up,down}.sql`, `atlas.sum`, `embedded.migrations.go` (embedded into the binary) |
| Migration runner | `services/go/platform/postgres/migrations.runner.go` (golang-migrate, applied at service start); money modules: `services/go/modules/ledger/src/databases/sharedPool.database.go` `ApplyModuleMigrationsAsSchemaOwner` (sets `-c role=svc_<m>`) |
| Queries (reads) | `<m>/src/modules/<feature>/queries/<name>/*.handler.go` |
| Commands (writes) | `<m>/src/modules/<feature>/commands/<name>/*.handler.go` |
| Domain services (most query code) | `<m>/src/modules/<feature>/services/*.service.go` (live: `<m>/src/services/*.service.go`) |
| Repositories (rare) | `admin/src/repositories/auditEvent.repository.go`, `wallet/src/repositories/accountDirectory.repository.go` (raw cross-schema read of `auth.accounts`) |
| Outbox writer | non-money: generated `OutboxEvent` entity; money: `ledger/src/events/outbox.event.go` (raw SQL, relay with retry + dead-letter) |
| DB integration tests | `<m>/src/**/*_integration_test.go`; money harness `ledger/src/databases/moneyTesting/` (`freshSchema.util.go`); `deployables/goLive/liveMoney.integration_test.go` |

## 5. Adding or changing a table (EXISTING workflow)

1. Edit `<m>/src/databases/schema/<entity>.schema.go` (indexes in `Indexes()`, CHECKs via `entsql.Checks` annotations).
2. `cd <m>/src/databases && go generate` (regenerates `src/generated/ent`).
3. `cd <m> && go run ./cmd/generateMigration <snake_name>` against `atlas_dev`.
4. Grants or protections are hand-written in a separate `<ts>_grant_*.up.sql` (+ `.down.sql`), then `go run ./cmd/generateMigration -rehash`.
5. Rules: money is `bigint *_minor` + `currency`; ids are UUIDv7; never add an ORM call that bypasses `RunInMoneyTransaction` for money tables; index changes follow [indexes.md](indexes.md); online-safety rules are in [migrations.md](migrations.md).

## 6. Grep recipes (use instead of repo-wide scans)

| Need | Command |
| --- | --- |
| All tables + indexes actually in the DB | `cat services/go/modules/*/src/migrations/*.up.sql` |
| Tables ent expects but migrations lack | compare `<m>/src/generated/ent/migrate/schema.go` with `<m>/src/migrations` |
| Every locking read | `grep -rn --include=*.go --exclude-dir=generated -E "ForUpdate\(|advisory" services/go/modules` |
| Every money transaction | `grep -rn --include=*.go --exclude-dir=generated "RunInMoneyTransaction\|RunIdempotentMoneyCommand" services/go/modules` |
| Raw SQL (should be grants + outbox only) | `grep -rn --include=*.go --exclude-dir=generated -E "\"(SELECT|INSERT|UPDATE|DELETE) " services/go/modules` |
| List queries | `grep -rn --include=*.go --exclude-dir=generated "\.All(ctx)" services/go/modules` |
| Cross-schema grants | `grep -h "GRANT SELECT" services/go/modules/*/src/migrations/*.up.sql` |
